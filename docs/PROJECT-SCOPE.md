# Final-Year Project Scope — AI Digital Twin + Portfolio Intelligence

## Problem

Static portfolios force recruiters to manually search pages and infer relationships between education, projects, skills, and experience. Generic chatbots improve navigation but often hallucinate because they are not grounded in evidence.

## Proposed system

Build a source-grounded AI Digital Twin that represents a person's professional knowledge and converts heterogeneous portfolio data into an interactive intelligence layer.

## Core objectives

1. Ground answers in verified personal documents using RAG.
2. Preserve conversation continuity with session-scoped persistent memory.
3. Convert unstructured sources into structured milestones, goals, and skill evidence.
4. Visualize professional growth as an interactive Life Map.
5. Provide an evidence-based Recruiter Mode for role-specific evaluation.
6. Enforce explicit privacy boundaries between private, twin-usable, and public data.
7. Measure retrieval quality, hallucination rate, citation precision, latency, and user usefulness.

## Major modules

- Document / knowledge ingestion
- Semantic chunking and embeddings
- Vector retrieval
- Conversation memory
- Response orchestration
- Evidence extraction
- Portfolio Intelligence / Life Map
- Recruiter Mode
- Owner admin workspace
- Privacy and access controls
- Telemetry and evaluation
